# Paradise Nursery

## Paradise Nursery Shopping Application

Paradise Nursery is an online plant shop application that allows users to browse and purchase beautiful houseplants.

The application provides a user-friendly shopping experience where customers can explore different categories of plants, add plants to their shopping cart, manage quantities, remove items, and view the total cost of their purchases.

## Project Features

- Paradise Nursery landing page
- Plant product listing
- Multiple plant categories
- Add plants to shopping cart
- Dynamic shopping cart count
- Increase and decrease item quantities
- Remove items from cart
- Calculate total shopping cart cost
- Continue shopping functionality
- Checkout Coming Soon message

## Technologies Used

- React Router
- JavaScript
